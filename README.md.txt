# Java Data Structures & OOP Practice

## Overview

This repository contains Java projects and exercises completed as part of **Java Programming at Saskatchewan Polytechnic**.  
The work focuses on core **object-oriented programming (OOP)** concepts, **custom data structures**, and **generic programming**, implemented using **Apache NetBeans**.

The code demonstrates how fundamental data structures work internally rather than relying on Java’s built-in collection frameworks.

---

## Key Concepts Covered

### Arrays & Dynamic Resizing

- Custom `ArrayManager` class to manage arrays of objects  
- Manual resizing using `System.arraycopy()`  
- Insert, remove, search, and traversal operations  
- Custom exceptions for error handling  

**Concepts:**
- `Object[]`, dynamic resizing, bounds checking, exception handling

---

### Singly Linked Lists

- Custom `LinkedList` and `ListNode` implementations  
- Node-based structure with `next` references  
- Supported operations:
  - add  
  - addBefore / addAfter  
  - removeCurrent  
  - traversal using start, advance, and end  

**Concepts:**
- Pointers, node traversal, linked list manipulation

---

### Doubly Linked Lists (Exam Preparation)

- Extended linked list logic to support:
  - `next` and `previous` references  
- Enables forward and backward traversal  
- Efficient insertion and removal at any position  

**Concepts:**
- Doubly linked lists, bidirectional traversal, pointer management

---

### Generics

- Generic linked list implementation (`GLinkedList<T>`)  
- Generic node class (`GListNode<T>`)  
- Type-safe data storage without casting  

**Concepts:**
- Java Generics, reusable data structures, type safety

---

### Comparisons & Interfaces

- `Widget` class implementing `Comparable`  
- Custom `equals()` and `compareTo()` methods  
- Finding largest elements and searching collections  

**Concepts:**
- Comparable, object comparison, sorting logic

---

### Object-Oriented Design

- Bank account simulation using:
  - Inheritance  
  - Polymorphism  
  - Composition  
- Driver-based program structure with menu logic  

**Concepts:**
- OOP principles, class relationships, real-world modeling

---
